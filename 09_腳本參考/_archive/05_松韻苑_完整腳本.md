## 1. 整體企劃概要

### 🎯 核心策略

**「用一隻貓的視角，講一個年輕夫妻找到家的故事」**

不直接賣建案，而是賣「家的感覺」。讓觀眾把豆豆貓帶入自己的生活想像 → 自然產生「這就是我想要的家」的共鳴。

### 🎬 三段式結構

```
Act 1（0-7 秒）│ 引入
   主人在找房 → 豆豆陪著探索 → 發現松韻苑
   👉 任務：抓住 3 秒留存率

Act 2（7-37 秒）│ 鋪陳
   外觀 → 大廳 → 空中花園 → 書房 → 健身房 → 客廳 → 陽台
   👉 任務：堆疊賣點，營造生活想像

Act 3（37-60 秒）│ 高潮 + CTA
   豆豆認證 → 品牌 slogan → 預約資訊
   👉 任務：促成行動
```

### 🪝 開頭 Hook 設計（前 3 秒）

**hook 公式：「異常的角色 + 熟悉的場景 + 懸念暗示」**

- 異常：一隻穿藍毛衣的橘貓
- 熟悉：台灣捷運車廂
- 懸念：認真看地圖（在找什麼？）

→ 用戶滑到這格，會多停 1-2 秒看「這隻貓在幹嘛」，達成 3 秒留存。

### 📣 CTA 策略

不用「期待您的光臨」這種弱 CTA。改用：

- **第一階 CTA**：「立即預約賞屋」（命令式 + 具體動作）
- **第二階 CTA**：「從捷運松竹站，走到您的新家」（情境式 + 行動動詞）
- **視覺輔助**：QR Code + 電話 + 接待中心地址

### 🚦 法規預先合規

- 影片片頭片尾全程加註「3D 示意圖，實際以建造完成為準」
- 公設、外觀、夜景所有 AI 生成畫面右下角加「示意圖」浮水印
- 不出現「保證升值」「全台最佳」等違規詞
- 捷運松竹站描述為「步行 3 分鐘」需符合實際距離（每分鐘 80 公尺）

## 5. ElevenLabs 配音稿

### 🎤 配音設定建議

- **聲音選擇**：女聲、溫柔、25-35 歲調性。推薦試聽 `Charlotte`、`Lily`、`Alice`，選最符合「文青姐姐」感的
- **語言**：Settings → 設成 Chinese (Mandarin)
- **Stability**：40-45（中等，保留情感變化）
- **Similarity Boost**：80
- **Style**：15-20（含情緒但不誇張）
- **Speaker Boost**：開啟

### 📝 完整配音稿（含情緒標記與停頓）

```
（語氣：溫柔好奇，像在分享日記）

我家主人啊…最近，在找新房子。〔停 0.3 秒〕

結果，走出捷運松竹站…他就停下了。〔語氣上揚〕

氣派雙電梯…〔小聲〕比我家樓下還寬敞呢。

11 樓的空中花園…〔放慢〕從這裡看，整個北屯都安靜了。

共讀書房裡…午後的陽光，最懂我。〔輕嘆一口氣〕

健身房…〔停一拍，語氣假裝抱怨〕呃，主人說我太胖了。

回家，是一天最美的儀式。〔放慢，溫柔〕

陽台的風…帶著洲際球場的歡呼。

〔語氣堅定可愛，加重〕豆豆…認證！

松韻苑，給家，最好的選擇。〔放慢，最後一字輕落〕

〔停 0.5 秒，轉換成介紹語氣〕
即日起，預約賞屋。從捷運松竹站…走到您的，新家。
```

### 📊 字數統計

| 項目 | 字數 |
|---|---|
| 純台詞 | 152 字 |
| 含情緒標記 | 200 字 |
| ElevenLabs 計算字數 | 約 160 字（情緒標記不算）|
| 免費額度消耗 | 1.6%（每月 10,000 字額度）|

> 💡 **重要**：括號內的情緒標記**不會被讀出來**，但 AI 會根據它調整語氣。如果你不希望有些標記影響太多，跑出來不滿意可以拿掉。

## 7. BGM 推薦

### 🎵 風格定調

「**溫暖鋼琴 + 輕柔木吉他 + 微弱風鈴**」三件套。建設業首購族最吃這套。

### 🔍 CapCut 音樂庫搜尋關鍵字

| 階段 | 關鍵字（CapCut 內搜） |
|---|---|
| 主軸推薦 | `heartwarming home`、`gentle piano family`、`cozy afternoon` |
| 備援選項 | `soft ukulele`、`acoustic warm`、`dreamy piano` |
| 高潮加強 | `uplifting piano build up`、`hopeful warm` |

### 🎼 節奏配置建議

```
0-7 秒（Hook 引入）｜ 鋼琴單音 + 環境音，營造日常感
7-37 秒（鋪陳）  ｜ 加入木吉他、節奏輕快
37-49 秒（高潮）  ｜ 旋律推升、弦樂加入
49-60 秒（CTA）   ｜ 收回鋼琴、留情緒餘韻
```

### ⚠️ 版權檢查

- CapCut 音樂庫的曲子標籤要看到「**Free for commercial**」或「**Authorized for ads**」
- 不確定的曲子，**寧可不用**也不要冒險被 FB / IG 廣告系統下架
- 如果客戶要求商用授權更嚴謹，可考慮 Epidemic Sound（$15/月）或 Artlist（$200/年）

## 8. 片頭片尾品牌視覺

### 🎨 整支影片視覺系統

#### 色彩規範（依建商 CI）
- **主色**：莫蘭迪綠 `#A8B5A0`

#### 字體規範
- **品牌主標**：思源宋體 Heavy（穩重感）
- **內文 / 字幕**：思源黑體 Medium

- 0-0.3 秒：建商 logo 淡入（極小、左上角）
- 0.3-0.5 秒：保留至全片結束（一直在角落，不打斷敘事）
