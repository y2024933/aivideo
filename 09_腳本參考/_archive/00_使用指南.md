> **版本**：免費版（純體驗 / 練手）
> **目標**：用 0 元工具完成第一支建案 AI 影片，驗證流程後再決定要不要升級付費工具

## 標準工作流程（接到一個案子怎麼跑）

```
[ 第 1 步：角色設定 ]
   ↓
打開「角色設定器」Artifact → 拉選單 → 複製 Prompt A
   ↓
貼到 Bing Image Creator → 產 4 張預覽 → 不滿意調參數 → 滿意後存圖
   ↓
複製「角色 DNA」字串 → 回到對話告訴 Claude

[ 第 2 步：腳本生成 ]
   ↓
打開「01_腳本生成範本.md」→ 填入建案資料、劇情、長度
   ↓
把整份範本貼回 Cowork 對話 → Claude 產出完整分鏡腳本

[ 第 3 步：四位 Reviewer 並行審查 ]
   ↓
告訴 Claude「啟動 4 位 reviewer 審查腳本」
   ↓
Claude 切換 4 種專家視角：腳本、Prompt、法規、品牌
   ↓
產出檢查報告 → 你決定哪些要修

[ 第 4 步：素材生產（用免費工具）]
   ↓
照「03_免費工具 SOP.md」操作：
   ├─ Bing Image Creator → 產所有鏡頭的關鍵畫面
   ├─ Kling 免費版（每天 6 次）→ 把圖變成動畫
   ├─ Luma 免費版（每月 30 段）→ 補充動畫
   ├─ ElevenLabs 免費（每月 10,000 字）→ 配音
   └─ Edge TTS（完全免費）→ 配音備用

[ 第 5 步：剪接交付 ]
   ↓
打開 CapCut 免費版 → 拖入素材 → 加字幕 BGM → 輸出 mp4
```

## 第一次使用：建議先跑「練習案例」

**強烈建議你第一次不要用真客戶的案子練手**，先用虛構的範例練一遍：

1. 打開 `04_練習案例.md` → 裡面有完整的虛構建案資料
2. 跟著流程走一次，看每個環節品質如何
3. 完成後評估：免費工具產出的影片你能不能接受？需不需要升級付費版？
4. 確認流程順了，再用真客戶資料正式接案

**預估第一次練手時間：4-6 小時**（含等 Bing 跑圖 + 等 Kling 渲染的時間）

## 重要原則

### 1. 角色一致性是免費版最大挑戰
免費的 Bing / Leonardo 沒有 Midjourney 的 `--cref` 功能，要靠「**重複使用同一段角色描述**」。所以「角色 DNA」字串要存好，每個鏡頭 prompt 都要把它放在最前面。

### 2. 法規 reviewer 一定要跑
建設業廣告地雷多，AI 生成的「未來街景 / 公設」**必須標註「示意圖」**，不然有違反公平交易法的風險。

### 3. 免費工具有額度限制
- Bing：每天免費，但跑得慢（10-30 秒一張），急用要等
- Kling：每天 6 段免費，5 秒一段，所以 60 秒影片要分 3 天才能完成（或一次只用免費，不夠的鏡頭留白）
- Luma：每月 30 段免費（補強 Kling 不夠）
- ElevenLabs：每月 10,000 字配音額度（夠用 5-10 支影片）

### 4. 「示意圖」三個字寫在哪
- 影片右上或左下角，全片浮水印
- 所有未來街景、公設、空景圖都要加
- 客戶交付時白紙黑字寫進合約

## 升級路線（什麼時候該付費）

跑完 1-2 個練習案後，你會明顯感覺到：

| 痛點 | 解法 | 成本 |
|---|---|---|
| 角色每張長不一樣 | 升級 Midjourney（`--cref`） | $10/月 |
| Bing 太慢、品質不穩 | 升級 Midjourney | 同上 |
| Kling 一天 6 次不夠 | 升級 Kling Standard | $7/月 |
| 配音字數不夠 | 升級 ElevenLabs Starter | $5/月 |
| 商用授權不安心 | 升級任一付費版 | 看上面 |

**最划算升級組合**：Midjourney $10 + Kling $7 + ElevenLabs $5 = **$22/月**（≈ NT$700）

接到第一個正式案子（NT$15,000+）就把這個訂下去，毛利率還是很高。
